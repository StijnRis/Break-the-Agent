Agents get a raster construction floor plan and must turn it into a formal schematic: walls, rooms, doors, windows, fixtures and scale. A scorer checks every element against the surveyed CAD file the drawing came from. Below is one complete run, replayed step by step.

Result

    
Each bar is a category match score from 0% to 100%. Its weight sets the maximum points it can add; the line under the category shows points earned. The weights add to 100%, and those points make up the overall reward. First is the actual submission; second shows only differences from the survey.
