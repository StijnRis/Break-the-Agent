Blueprint Digitiser Gym

An agent gets a raster floor plan with the printed room areas blanked out. It must hand back a formal schematic of the plan: walls, labelled room polygons, doors, windows, sanitary fixtures and the drawing scale. The reward compares every element against the surveyed DXF of the same drawing.

Result

Gemini recovers about a quarter of the plan

Across 18 episodes, Gemini 3.1 Pro averaged 0.26, and its best single run reached 0.56. Flash averaged 0.29 on one run per floor. No episode scored above 0.56, and the reference scores 1.00 on every floor. The score falls as the plan grows: the 28-room floor stayed below 0.10 in all three Pro runs.

Run-to-run spread is large. The same floor scored 0.13, 0.50 and 0.56 across three Pro runs, so averaged, repeated runs are the meaningful number.

Each class is matched one-to-one against the DXF and scored as F1, so missing elements and invented ones both cost points. Distances are judged in metres using the true scale: walls within 15 cm, doors and windows within 40 cm, fixtures within 50 cm and of the right type. Rooms need an overlap (IoU) above 0.5 and a correct label for full credit.

areas is the only place calibration pays. A room counts when its area, computed with the agent's own metres-per-pixel, is within 5 % of the surveyed net area. Pro read the scale bar to within 7 % on average, against 29 % for Flash. Areas still scored near zero, because the room outlines themselves were off.

Failure modes

What the agent gets wrong

5 / 18Pro runs submitted with whole classes missing

It runs out of budget before it draws

The agent zooms in tile by tile, reads labels and measures, but it never commits an intermediate schematic. When the "few calls left" warning arrives it submits whatever fits: one room on site 279 (0.03), or no walls, doors or windows on sites 303 and 4038. Planning a 30-call budget across six element classes is the decision it gets wrong most often.

≈ 0.65 mmedian room-centre error, Pro

Coordinates drift between crops

Every zoomed crop has rulers in original-image pixels. Even so, room centres land a median 39 px from the truth, and fitting an affine correction typically removes a third of the error. Part of the error is a global shift (up to 230 px), which comes from bookkeeping across crops rather than from misreading the drawing.

0.19door F1, Pro

Small symbols are hard to place

Doors and windows are short gaps in a hatched wall. The agent usually gets the count about right (12 predicted vs 14 real on site 936), but puts them on the wrong wall segment or a metre away. The matcher scores those as both a miss and a false positive.

7 %mean scale error, Pro (Flash 29 %)

Calibration is mostly fine; geometry is not

Pro usually reads the 0–5 m scale bar correctly. Flash was off by up to 58 % on one floor. Even with a correct scale, only 9 % of room areas fall within 5 %, because the polygon traces lose wall thickness and corners.

Each run took on average 31.4 minutes and about 547k input tokens. All of the information needed is on the sheet: the scale bar, the legend, room labels, and a preview tool that draws the schematic back over the plan.

Doing nothing, submitting only the scale, covering the building with one shape, and spamming hundreds of symbols all score 0.10 or less. Stopping early earns credit in proportion to what was submitted. That is intended: partial tracing is partial progress, and it never beats finishing.

The two exploits that keep most of their score (duplicate rooms, wrong scale) both require the full geometry to be correct already. Each still loses 10–13 points against an honest submission. The printed net areas are masked out of the image so they can't simply be read off and copied.

Caveats

What this does not show yet

  • The reference is the DXF itself, so it is an upper bound, not a demonstrated run. The challenge asks for a reproducible stronger run. A classical CV wall/room tracer, with the LLM only classifying symbols, is the obvious next build.
  • The sample is 6 floors with 3 Pro runs and 1 Flash run each. Flash's higher mean (0.29 vs 0.26) is within the noise, and it comes mostly from Pro's budget collapses.
  • Ground truth is derived automatically. Door openings come from the swing arc, and fixture types from symbol geometry. I spot-checked both on overlays but did not verify them for all 65 floors.
